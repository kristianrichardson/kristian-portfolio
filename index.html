Who I Am

I'm a Cyber Security Specialist in engineering at Lloyds Banking Group, responsible for implementing and maintaining security controls that protect the financial data of millions of UK customers. My work spans Identity and Access Management (IAM), zero trust tooling, and automating security across the Group's platforms and services.

I engineer security automation across CI/CD pipelines — ensuring controls are built into the delivery lifecycle rather than bolted on at the end. Working closely with engineering teams, I embed zero trust principles and security tooling throughout the development process, from code to production.

Outside of LBG, I develop purpose-built security research tools in Python — web vulnerability scanners, network reconnaissance engines, and research instrumentation built from the ground up. This continuous research sharpens my understanding of adversarial techniques and directly informs the defensive posture I help shape professionally. I also speak publicly on cybersecurity and mentor the next generation of digital professionals.

What I've Built

🔍
Advanced Web Vulnerability Scanner

A fully custom async web vulnerability scanner built for bug bounty hunting and offensive security research. Every module, detection technique, and evasion mechanism is hand-written in Python — no wrappers, no black boxes.

Python asyncio httpx Playwright PyQt6 SQLite Jinja2
🔍18 vulnerability modules — SQLi, XSS, SSRF, SSTI, XXE, LFI, CMDi, IDOR, CORS, Cache Poisoning, HTTP Smuggling, GraphQL & more
🧠Differential analysis engine — statistically baselines each parameter to cut false positives before a single payload fires
📡Out-of-band detection via interactsh — catches blind SQLi, SSRF, CMDi & XXE that never surface in the response body
🕵️WAF fingerprinting + evasion — auto-detects Cloudflare, Akamai, AWS WAF, ModSecurity, Imperva and applies encoding/mutation bypasses
🕸️Smart crawling — static HTML, form extraction, JS endpoint parsing, Playwright SPA rendering for React/Vue/Angular
⛓️Exploit chain detection — correlates low-severity findings into critical chains (e.g. Open Redirect → SSRF)
🖥️Desktop GUI in PyQt6 — dark themed, live findings feed, log console, severity dashboard — like a lightweight Burp Suite

Multi-Mode Port Scanner

A multi-threaded port scanning engine capable of operating across a wide range of protocols and scanning techniques. Supports standard discovery and evasive scan modes — including Fragmentation and Stealth modes designed to operate against detection systems. Results output in both text and Excel formats for reporting and data analysis. Inspired by Nmap and built from the ground up in Python.
